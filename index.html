Interactive Physics · Dynamic Light Scattering

DLS Explainer Suite

Self-contained, interactive pages that illustrate the physics of Dynamic Light Scattering. Each one isolates a single variable and shows, in real time, how it shapes the scattered-intensity history and the resulting autocorrelation function.

Built by Daniel P. Seeman, Ph.D. — about.me/danielseeman

01

Particle Size

Watch Brownian motion set the fluctuation timescale, and size a particle from the autocorrelation decay.
02

Laser Wavelength

How the beam wavelength sets the scattering vector q and the decay rate. The trace is colored to the beam.
03

Scattering Angle · Goniometer

Sweep the detection angle continuously (8°–155°) and see the decay rate shift as q².
04

Fixed Angles · Benchtop

Compare forward (15°), right-angle (90°), and backscatter (173°) detection on a benchtop instrument.
05

Correlator Delay Window

Set the first and last delay times and see the range of dynamics a correlator can actually resolve.

Blank Template

An empty scaffold — layout, styling, and shared physics helpers — for building a new explainer page.
Every page is a single HTML file: no build step, no dependencies, no network calls. Open any file directly, or view the source on GitHub. Physics shared across all pages: D = k_B·T / (3πηd), q = (4πn/λ₀)·sin(θ/2), Γ = D·q².
